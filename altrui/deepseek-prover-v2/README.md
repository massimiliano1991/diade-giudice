# Proofs by others, kept here only because their source has no fetchable `.lean`

The judge (`giudice_altrui.yml`, `giudice_su_richiesta.yml`) downloads the proof it judges from its
source and never republishes it. This folder is the exception: proofs whose source is a paper, where
the Lean text exists only inside an HTML or PDF listing and cannot be fetched as a file. Each file is
a byte-exact extraction; its provenance and the way to redo the extraction are written here, so the
sha256 can be checked by anyone.

  Reasoning via Reinforcement Learning for Subgoal Decomposition*, Appendix B, titled in v2
  «Examples of the Buggy Proofs Generated by DeepSeek-Prover-V2-7B on PutnamBench Triggering the User
  Interface Bug of `apply?`». The paper itself presents this proof as buggy.
- **Extraction:** in `https://arxiv.org/html/2504.21801v2`, `<section id="A2">` holds two listings

  is the first string, base64-decoded, byte for byte (1038 bytes, no trailing newline). Not reflowed, not
  reindented. The same two strings, byte-identical, are in v1 (30 Apr 2025), whose Appendix B was titled
  «Examples of the Proofs Generated by DeepSeek-Prover-V2-7B on PutnamBench»: v2 changed the title, not
  the listing.
- **sha256:** `066b396952f374c7a1a962ddaccfb10cbfd4ee6120c72f317de209657792a202`
  (with one trailing `\n` appended, as a text editor would save it: `4987e9aa18eff320a064b23999dbb6541f0c04da5c30a0568187251fc3d81e78`).

### Redo it

The commands below need nothing from this repository. They fetch the paper's HTML (v2), take the **first**
`data:text/plain;base64,…` string after `<section id="A2">` (Appendix B in arXiv's HTML), decode it with
**no trailing newline**, and hash it. Expected output: the full sha256 on the last line.

```sh
curl -sL -o paper.html https://arxiv.org/html/2504.21801v2
python3 -c "import re,base64,sys;h=open('paper.html',encoding='utf-8').read();s=h[h.index('<section id=\"A2\"'):];sys.stdout.buffer.write(base64.b64decode(re.search(r'data:text/plain;base64,([A-Za-z0-9+/=]+)',s).group(1)))" > putnam_2005_a4_appB_v2.lean
shasum -a 256 putnam_2005_a4_appB_v2.lean
```
